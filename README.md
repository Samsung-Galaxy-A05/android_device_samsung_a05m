# Device tree for the Samsung Galaxy A05 (a05m)

## Device specifications

| Basic                   | Spec                                                        |
| ----------------------- | :---------------------------------------------------------- |
| SoC                     | Mediatek Helio G85 (12 nm)                                  |
| CPU                     | Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)     |
| GPU                     | Mali-G52 MC2                                                |
| Memory                  | 4/6GB                                                       |
| Shipped Android version | 13                                                          |
| Storage                 | 64/128GB                                                    |
| MicroSD                 | MicroSDXC                                                   |
| Battery                 | Non-removable Li-Po 5000 mAh                                |
| Display                 | 720 x 1650 pixels, 6.7 inches                               |
| Rear Camera 1           | 50 MP, f/1.8, (wide), 1/2.8", 0.64µm, AF                    |
| Rear Camera 2           | 2 MP (auxiliary lens)                                       |
| Front Camera            | 8 MP                                                        |
